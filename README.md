# BalanceControlSystem

BalanceControlSystem — библиотека контроля отрицательных остатков для всех. Работает на 1С Предприятие 8.3. Система не даёт уйти в минус регистрам накопления остатков, в каком бы порядке ни записывали, проводили, распроводили и сдвигали по времени документы.

Другие открытые проекты DNS: [github.com/dns-technologies](https://github.com/dns-technologies)

## Подключение

1. Перенести объекты нужного варианта в конфигурацию.
2. Добавить тип объекта документа (`DocumentObject.<Имя>` / `ДокументОбъект.<Имя>`)
   в определяемый тип документов под контролем.
3. Добавить тип набора записей регистра остатков (`AccumulationRegisterRecordSet.<Имя>` /
   `РегистрНакопленияНаборЗаписей.<Имя>`) в определяемый тип регистров под контролем.

Остальное подхватят подписки, в модулях документов и регистров ничего писать не нужно.
В поставке определяемые типы пустые. Пустой тип в источнике подписки платформа не принимает,
поэтому конфигурация сохранится, когда в типе документов появится хотя бы один документ.

Требования: платформа 8.3 (проверено на 8.3.27), управляемый режим блокировок.

## Настройка

Переопределяемый модуль позволяет:

- `OnDefineControlRequired` / `ПриОпределенииНеобходимостиКонтроля` — пропустить контроль
  для конкретной записи;
- `OnDefineControlledResources` / `ПриОпределенииКонтролируемыхРесурсов` — контролировать
  только часть ресурсов;
- `OnGenerateRefusalText` / `ПриФормированииТекстаОтказа` — заменить текст отказа;
- `OnDefineRefusalLoggingRequired` / `ПриОпределенииНеобходимостиЛогирования` — отключить запись
  отказа в журнал регистрации.

Систему целиком отключает константа `DisableBalanceControlSystem` / `ОтключитьСистемуКонтроляОстатков`.
